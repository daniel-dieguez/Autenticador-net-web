# **Authentication Frontend - React.js**  

This project is a **user authentication system** built with **React.js**. It provides a login interface for users to authenticate and access protected resources. It integrates with a .NET 8 backend and SQL Server for secure authentication.  

## **Features**  
✅ User login and logout  
✅ Secure session handling with JWT  
✅ Form validation and error handling  
✅ Responsive design for mobile and desktop  
✅ Integration with a .NET 8 authentication API  

## **Technologies Used**  
- **Frontend:** React.js  
- **State Management:** useState, useEffect  
- **Routing:** React Router  
- **Styling:** CSS Modules  
- **API Communication:** Fetch/Axios
